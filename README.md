# My Portfolio

This is a personal portfolio website built with React, TanStack Router, Tailwind CSS, and Bun/Vite.

## Prerequisites

- Node.js or Bun installed
- Git (optional)

## Install dependencies

If you use Bun:

```bash
bun install
```

If you use npm:

```bash
npm install
```

## Start development server

```bash
bun run dev
```

or with npm:

```bash
npm run dev
```

Then open the URL shown in the terminal, typically `http://localhost:5173`.

## Build for production

```bash
bun run build
```

or with npm:

```bash
npm run build
```

## Preview production build

```bash
bun run preview
```

or with npm:

```bash
npm run preview
```

## Notes

- The main page is defined in `src/routes/index.tsx`.
- Static assets and components are under `src/assets` and `src/components`.
- Update project metadata in `src/routes/__root.tsx`.
